# SAFit - Mesure de puissance sur ergocycle par vision haute fréquence

Projet de Fin d'Études (PFE) - ENSC Bordeaux, en partenariat avec la plateforme SMART de l'Université de Bordeaux (encadré par le Pr Laurent Arsac).

## Objectif
Application mobile Flutter permettant de mesurer la puissance mécanique développée sur un ergocycle via la caméra haute fréquence du smartphone (détection de traits à 240 fps) et la fréquence cardiaque via une ceinture Bluetooth Polar H10.
